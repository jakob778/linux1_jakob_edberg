Byta directory:

```bash
cd
```

Se vart du är/absolut path:

```bash
pwd
```

Lista filer i directory:

```bash
ls
```

Gå till home, user, root:

```bash
cd /home
cd ~
cd /
```

Gå upp ett steg i directory/parent directory:

```bash
cd ..
```

Visa paths nedåt från aktuellt directory:

```bash
tree .
```
